# SSLTool

一个扁平化界面的 SSL / SSH / SFTP 桌面客户端（Python + PyQt5）。

> English version: [README.en.md](README.en.md)

## 功能

- **SSH 终端**：密码 / 私钥登录，基于 pyte 的完整 VT100/VT220 终端（ANSI 彩色），支持备用屏幕（`vim` / `less` / `top` 等全屏程序正常显示），本地回显自动去重
- **终端体验增强**：会话日志（自动保存到 `~/.ssltool/logs/`，带时间戳，标签页内可开关）、终端内搜索（Ctrl+F）、URL 识别（Ctrl+点击用浏览器打开，右键菜单可复制 / 打开）、括号粘贴（多行粘贴作为一个整体安全发送，防止逐行被当作命令执行）
- **SSL 加密通道**：原始 TLS 文本控制台（类似 telnet-over-TLS），连接后显示服务器证书 SHA-256 指纹、TLS 版本与加密套件；可选证书验证与客户端证书
- **SFTP 文件管理**：目录浏览、**多选批量上传 / 下载**（支持文件夹递归与总进度）、**断点续传**（下载中断后从断点继续，目标已完整则跳过）、**拖拽上传 / 下载**、**传输可取消**、右键菜单（下载 / 复制路径 / 重命名 / 删除）、新建文件夹、**SFTP 只读模式**（禁止上传 / 删除 / 修改）
- **SSH 跳板机（ProxyJump）**：经跳板机连接目标服务器（SSH 终端与 SFTP 均支持），跳板机密钥同样走 TOFU 确认，确认之前不会向跳板机发送任何凭据
- **SSH 端口转发**：本地转发（-L）、远程转发（-R）、动态 SOCKS5 代理（-D），会话配置里一行一条规则；连接后启动结果直接显示在终端里
- **会话管理**：连接配置保存于 `~/.ssltool/sessions.json`；支持**会话分组**（树形展示，可折叠）、**搜索过滤**、**导入 / 导出**（JSON 格式，导入时同名会话按 ID 合并更新）；密码与私钥口令存入系统钥匙串（keyring），无可用后端时回退到 `~/.ssltool/secrets.json`——Windows 下用 DPAPI（Windows 数据保护 API）加密，仅当前 Windows 用户可解密；其他平台回退为混淆格式（不推荐，建议安装 keyring 后端）
- **深色主题**：菜单「视图 → 深色主题」（Ctrl+D）一键切换，偏好自动保存

## 安全

- **SSH 主机密钥验证（TOFU）**：连接时先做一次只含密钥交换的探测连接取回服务器主机密钥，与 `~/.ssltool/known_hosts.json` 比对——**在发送密码 / 私钥签名之前**完成校验。首次连接弹出指纹确认框（可与管理员公布的指纹比对）；已记录密钥发生变化时弹出醒目警告（疑似中间人攻击）；认证连接建立后还会复核实际密钥指纹，防止两条 TCP 连接被分别劫持
- **凭据加密**：回退存储的密码在 Windows 上用 DPAPI 加密（见上）
- **SSL 证书详情**：连接后显示服务器证书 SHA-256 指纹、主题 / 颁发者 / 序列号 / SAN、有效期，并给出到期（<30 天）与已过期警告

## 安装与运行

1. 安装 Python 3.8+
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python main.py`（或双击 `run.bat`）

## 打包为可执行文件

双击 `build.bat`（使用 PyInstaller，输出到 `dist\SSLTool`）。

## 使用说明

1. 左侧「快速连接」输入主机 / 端口 / 用户名并选择协议后点「连接」，或通过「新建连接」保存会话
2. SSH 密码未保存时，连接前会弹框询问；勾选「记住密码」后存入系统钥匙串，下次免输入
3. 私钥支持 OpenSSH / PEM 格式（RSA / Ed25519 / ECDSA / DSA），不支持 `.ppk`（Paramiko 限制）；需要口令的私钥会在连接时弹框询问
4. SSL 加密通道为原始 TLS 文本控制台，默认开启本地回显，适合连接基于 TLS 的文本服务（如 openssl s_server 演示服务）
5. 终端默认开启「本地回显」：键入内容立即在本地显示，并自动去除服务器的重复回显——无论服务器是否回显，每个字符都只显示一次；若显示仍有异常，可取消勾选标签页左上角的「本地回显」
6. 若程序异常退出，可在 `~/.ssltool/error.log` 查看崩溃记录
7. SFTP 支持拖拽：从文件管理器把文件 / 文件夹拖入右侧远程目录树即上传；把远程项目拖到左侧本地目录树即下载到对应文件夹
8. 传输进行中可点进度框「取消」停止本批传输；取消后剩余未开始的传输会被丢弃
9. 菜单「视图 → 深色主题」（Ctrl+D）切换深色模式，重启后保持
10. SSH 端口转发：在「新建 / 编辑连接」对话框的「端口转发」框里每行写一条规则，OpenSSH 风格（端口写 `0` 表示自动分配）：
    - `L:127.0.0.1:8080:10.0.0.5:80` —— 本机 8080 → 服务器可达的 10.0.0.5:80（本地转发）
    - `R:127.0.0.1:0:127.0.0.1:3306` —— 服务器随机端口 → 本机 3306（远程转发）
    - `D:127.0.0.1:1080` —— 本机 SOCKS5 代理（仅 CONNECT、无认证）
    连接后每个转发的实际监听端口会打印在终端里；断开连接时全部自动关闭。
11. 跳板机（ProxyJump）：在「新建 / 编辑连接」对话框的「跳板机」区域填写跳板机地址 / 端口 / 用户名与认证方式（密码或私钥），填写地址即启用；SSH 终端与 SFTP 都经跳板机连接目标。跳板机密码在连接时询问、不保存
12. SFTP 只读模式：会话勾选「SFTP 只读模式」后，上传 / 新建文件夹 / 重命名 / 删除与拖拽全部禁用，只能浏览与下载
13. SFTP 断点续传：下载文件时若本地同名文件已存在，会询问「续传 / 覆盖 / 取消」；续传从本地已有字节数继续（目录批量下载时逐个询问，已完整的目标自动跳过）
14. 会话分组与搜索：新建 / 编辑连接时填写「分组」（留空为未分组）；左侧会话列表按分组折叠展示；会话列表上方搜索框按名称 / 主机实时过滤
15. 导入 / 导出：菜单「会话 → 导出会话…」把全部会话（不含密码）导出为 JSON 备份；「导入会话…」读入 JSON，同名会话（ID 相同）更新、新会话追加

## 快捷键（终端内）

| 按键 | 作用 |
| --- | --- |
| Ctrl+C | 发送中断信号 `\x03`（有选中文本时复制） |
| Ctrl+Shift+C | 复制选中文本 |
| Ctrl+V / Ctrl+Shift+V | 粘贴并发送（自动括号粘贴） |
| Ctrl+F | 终端内搜索（Enter 下一个，Shift+Enter 上一个，Esc 关闭） |
| Ctrl+点击 URL | 用系统浏览器打开链接 |
| Ctrl+A | 全选 |
| 方向键 / Home / End / Ins / Del | 发送对应转义序列 |
| PgUp / PgDn | 回看滚动缓冲 |
| Shift+PgUp / Shift+PgDn | 发送 `\x1b[5~` / `\x1b[6~` 转义序列 |

## 说明与限制

- 终端基于 pyte 的 VT100/VT220 模拟：支持 xterm 16/256 色、粗体 / 下划线 / 反显、滚动缓冲，以及备用屏幕（alt-screen，1049 / 47 模式——`vim`、`less`、`top` 等全屏程序在独立屏幕缓冲中运行，退出后自动恢复主屏）
- SSH 主机密钥采用「首次使用信任（TOFU）」策略：首次连接需人工确认指纹，密钥变化时警告（详见「安全」一节）；确认记录保存于 `~/.ssltool/known_hosts.json`
- 端口转发规则不支持 IPv6 字面量地址；SOCKS5 仅支持 CONNECT 命令与无认证模式
- 跳板机认证仅支持密码与私钥两种方式，跳板机密码不保存（每次连接时询问）；目标与跳板机的主机密钥都走 TOFU 确认流程
